# Sample output

Generated by `npm run generate:sample` in deterministic mode (no API key), from [`data/examples/briefing.sample.json`](../../data/examples/briefing.sample.json).

- `sample-deck.pptx`: the deck, with speaker notes
- `quality-report.json`: the QA report for it
- `previews/`: one image per slide, rendered with macOS Quick Look

The slide copy is placeholder text built from the brief. With an API key the model writes the copy and the same layout engine and QA rules apply to it.
